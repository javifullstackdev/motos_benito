# Motos Benito — Sistema de Facturación

Aplicación web de gestión y facturación para Motos Benito, cadena de talleres de motocicletas con sede en Colmenar de Oreja y Aranjuez.

## Estado del proyecto
🚧 En desarrollo — Fase 0: configuración inicial del entorno.

## Stack tecnológico
- Frontend: React + TypeScript + Vite + Tailwind CSS
- Backend: Node.js + Express + TypeScript
- Base de datos: PostgreSQL + Prisma ORM
- Generación de PDF: Puppeteer
